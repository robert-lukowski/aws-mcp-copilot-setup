AWS MCP setup pilot 0.2.1 - validation report
Date: 2026-11-26
Runtime: PowerShell 7.4.13 on Linux

PASS: 63 core assertions
- JSON merge preserves other servers, root fields, tool restrictions and env.
- Repeated configuration is idempotent.
- Invalid JSON, duplicate profiles and remote/auth entries are rejected.
- Custom flags, headers, wrappers and nonstandard proxy arguments are rejected without editing the entry.
- Existing custom AWS paths are resolved consistently; explicit process paths win.
- Rollback preserves unrelated later edits and refuses changes to its target.
- Writes roundtrip with spaces/backslashes, use UTF-8 without BOM and atomic replacement.
- Changed files are not overwritten by stale setup snapshots.
- PowerShell source syntax parsed without errors.

PASS: 20 mocked workflow assertions
- Setup writes intended configuration and an applied rollback record.
- Original configuration is backed up.
- Re-running setup does not rewrite configuration or duplicate backups.
- Rollback restores the server entry and retains unrelated later changes.
- Unexpected AWS account identity stops setup without editing MCP configuration.
- Arbitrary profile names and same-account profiles are accepted in order.
- Duplicate profile names stop setup without editing MCP configuration.
- Three- and five-profile setups preserve ordering and list every profile in the MCP verification prompt.
- A wrong fifth account stops setup before configuration is changed.

PASS: 25 prerequisite assertions (mocked installer calls)

- Success without a discoverable executable is rejected.
