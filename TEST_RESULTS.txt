AWS MCP setup pilot 0.2.0 - validation report
Date: 2026-11-25
Runtime: PowerShell 7.4.13 on Linux

PASS: 59 core assertions
- JSON merge preserves other servers, root fields, tool restrictions and env.

- Custom flags, headers, wrappers and nonstandard proxy arguments are rejected without editing the entry.

- Changed files are not overwritten by stale setup snapshots.
- PowerShell source syntax parsed without errors.
